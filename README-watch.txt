U613 для Amazfit Bip Max (Zepp OS) — базовая версия
====================================================
Что это: маленькое приложение на часах. Кнопка «Связь» проверяет связь с приложением LuvU613 на телефоне (ничего не меняет),
кнопка «+1 час (кровь)» шлёт настоящее событие «час» (добавит час занятию 🩸 в статистику, как раньше).

Как это работает
  часы -> приложение Zepp на телефоне (Side Service) -> локальный сервер в LuvU613 (127.0.0.1:28613) -> ответ обратно на часы.
  В LuvU613 версии 5.8 для этого появилась служба «Связь с часами» (постоянное уведомление). Она запускается при открытии приложения.

СБОРКА И УСТАНОВКА
1. Создайте НОВЫЙ репозиторий на GitHub. Он должен быть ПУБЛИЧНЫМ: часы скачивают пакет без входа в аккаунт.
   В этом проекте нет паролей и ключей, так что публичный репозиторий безопасен.
2. Загрузите в него всё содержимое этой папки (Add file -> Upload files).
3. Создайте вручную файл .github/workflows/build-watch.yml (Add file -> Create new file) и вставьте в него содержимое файла build-watch.yml из архива.
4. Откройте вкладку Actions и дождитесь зелёной галочки (2–4 минуты). Первый запуск создаёт ветку gh-pages.
5. Один раз включите Pages: Settings -> Pages -> Source: Deploy from a branch -> ветка gh-pages, папка / (root) -> Save. Подождите минуту-две.
6. Откройте справа на главной странице репозитория раздел Releases -> релиз v1.0.0. В нём QR-коды по моделям часов.
   Выберите QR для квадратного экрана 432x514 (в названии square-432x514). Откройте эту страницу на экране компьютера.
7. Телефон: в приложении Zepp включите режим разработчика (Профиль -> Настройки -> О приложении, несколько раз подряд нажмите на логотип/номер версии, пока не появится сообщение).
   Затем Профиль -> ваши часы -> Developer Mode -> значок «+»/сканер. Наведите камеру на QR с экрана компьютера.
   Если телефон не может отсканировать свой экран, в сканере есть кнопка выбора картинки из галереи.
8. Установка идёт по Bluetooth, около минуты. Приложение U613 появится в списке приложений на часах.
9. Установите на телефон LuvU613 5.8 и один раз откройте его (появится уведомление «Связь с часами»).
   Приложению Zepp и LuvU613 в настройках батареи поставьте «Без ограничений», иначе Android может их усыплять.
10. На часах откройте U613 и нажмите «Связь». Должно появиться «Связь есть: OK».

Если сборка красная — откройте запуск в Actions, там написана причина. Артефакт U613-watch-build содержит .zab и пакеты.
Запасной путь на компьютере (нужны Node.js 18–22 и аккаунт Zepp): npm i -g @zeppos/zeus-cli, затем zeus login, в папке проекта zeus preview — появится QR для сканера Zepp.

ЭТО НЕ ПРОВЕРЕНО НА ЧАСАХ. Самое слабое место — локальный адрес 127.0.0.1: в приложении Zepp он должен быть разрешён для обычного http.
Если на часах пишет «Телефон не ответил», пришлите текст этой надписи.
